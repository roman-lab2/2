# Autera — static publication

Target origin: https://autera-avtoservis.sourcecraft.site

This directory is ready to push to a public SourceCraft repository in a public organization. Use a repository with exactly the organization's name and make main the default branch. The root address is required because the website uses root-relative navigation and assets.

Source: https://github.com/roman-lab2/2/tree/codex/autera-sourcecraft

Preparing files does not publish a website or reserve the address. Do not change the working Google Apps Script worker token. After verifying the new website, update only its AUTERA.siteUrl and save the existing script.
